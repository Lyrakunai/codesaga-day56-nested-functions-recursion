# Day 56 — Nested Functions, `nonlocal` & Recursion

## Topics Covered 📘
- Nested Functions
- `nonlocal` Keyword
- Recursive Functions
- Base Case and Recursive Case
- Call Flow and Return Flow
- Recursive Return Values

## What I Learned 🧠
- How nested functions access enclosing variables.
- How `nonlocal` updates a variable in the enclosing scope.
- How recursion works using a base case and recursive calls.
- How each recursive call has its own local execution context.
- How return values travel back through recursive calls.
- The difference between `return inner` and `return inner()`.

## Key Concepts 📝
- **Nested Function:** A function defined inside another function.
- **`nonlocal`:** Allows updating a variable in an enclosing function scope.
- **Recursion:** A function calling itself.
- **Base Case:** The condition that stops recursion.
- **Return Flow:** Results returning to previous function calls.
